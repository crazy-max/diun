# Diun v4.34 to v4.35

## Move registry credentials to `auth.static`

Registry credentials now belong under `auth.static`. The top-level `username`,
`usernameFile`, `password`, and `passwordFile` fields are deprecated. Existing
settings still work, but emit deprecation warnings.

Move these fields into the `auth.static` block of each registry entry:

!!! example "v4.34"
    ```yaml
    regopts:
      - name: myregistry
        username: foo
        passwordFile: /run/secrets/registry-password
    ```

!!! example "v4.35"
    ```yaml
    regopts:
      - name: myregistry
        auth:
          static:
            username: foo
            passwordFile: /run/secrets/registry-password
    ```

Move `usernameFile` and `password` in the same way if you use them. Keep `name`,
`selector`, `timeout`, and `insecureTLS` at the registry entry level. Existing
`regopt` references, labels, and annotations do not need to change.

Rename the corresponding environment variables, keeping the same entry index
and values:

| Before                        | After                                     |
|-------------------------------|-------------------------------------------|
| `DIUN_REGOPTS_0_USERNAME`     | `DIUN_REGOPTS_0_AUTH_STATIC_USERNAME`     |
| `DIUN_REGOPTS_0_USERNAMEFILE` | `DIUN_REGOPTS_0_AUTH_STATIC_USERNAMEFILE` |
| `DIUN_REGOPTS_0_PASSWORD`     | `DIUN_REGOPTS_0_AUTH_STATIC_PASSWORD`     |
| `DIUN_REGOPTS_0_PASSWORDFILE` | `DIUN_REGOPTS_0_AUTH_STATIC_PASSWORDFILE` |

Remove the old fields and environment variables when migrating. Combining
top-level credentials with an `auth` block is a configuration error.

A username or username file is required for `auth.static`. Inline `username`
and `password` values still take precedence over their corresponding files.
If a credential file cannot be read, Diun now skips the image check instead of
continuing with partial credentials or falling back to Docker credentials.
This also applies to the deprecated top-level fields.

If you already rely on Docker configuration files or credential helpers, no
migration is needed. Leave `auth` unset to continue using credential discovery.

See [static authentication](../config/regopts.md#authstatic) for details.
