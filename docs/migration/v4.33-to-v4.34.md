# Diun v4.33 to v4.34

## Replace `watchRepo` with `watchMode`

`watchRepo` is deprecated in favor of `watchMode`. Existing settings still work,
but emit deprecation warnings. Replace `true` with `all` and `false` with `tag`
to preserve the existing behavior.

!!! example "v4.33"
    ```yaml
    defaults:
      watchRepo: true
    ```

!!! example "v4.34"
    ```yaml
    defaults:
      watchMode: all
    ```

Update the equivalent settings for your provider or configuration source:

| Configuration          | Before                         | After                         |
|------------------------|--------------------------------|-------------------------------|
| Environment variable   | `DIUN_DEFAULTS_WATCHREPO=true` | `DIUN_DEFAULTS_WATCHMODE=all` |
| Labels and annotations | `diun.watch_repo=true`         | `diun.watch_mode=all`         |
| File provider          | `watch_repo: true`             | `watch_mode: all`             |

Dockerfile annotations use the same names as labels. For each setting above,
replace `false` with `tag` instead of `all`.

Per-image settings override global defaults, including legacy settings. If both
options are set at the same level, `watchMode` takes precedence. Remove the
legacy option to stop its deprecation warning.

## Watch newer semantic versions

To watch versions newer than the configured tag, use `semver` for stable
releases or `semver+prereleases` to include prereleases:

```yaml
- name: nginx:1.27.0
  watch_mode: semver
```

These modes require a full semantic version and continue checking the configured
image. See [watch modes](../config/defaults.md#watchmode) for details.
